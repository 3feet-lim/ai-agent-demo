# 코드 리뷰 스킬 (Code Review Skill)

코드 리뷰 시 참고하는 체크리스트와 기준입니다.

## 심각도 분류 기준

| 심각도 | 아이콘 | 기준 | 예시 |
|--------|--------|------|------|
| Critical | 🔴 | 즉시 수정 필요 | 보안 취약점, 데이터 손실, 인증 우회 |
| Warning | 🟠 | 수정 권장 | 잠재적 버그, 성능 병목, 미처리 에러 |
| Suggestion | 🟡 | 개선 권장 | 가독성, 중복 코드, 네이밍 |
| Info | 🔵 | 참고 사항 | 대안 제시, 패턴 추천 |

## Python/FastAPI 체크리스트

### 보안
- [ ] 사용자 입력이 검증(validation)되는가
- [ ] SQL 인젝션 방지 (ORM 또는 파라미터 바인딩 사용)
- [ ] 민감 정보가 하드코딩되어 있지 않은가
- [ ] 적절한 인증/인가 처리가 되어 있는가
- [ ] CORS 설정이 적절한가

### 코드 품질
- [ ] 타입 힌트가 모든 함수에 적용되어 있는가
- [ ] 함수가 단일 책임 원칙(SRP)을 따르는가
- [ ] 에러 처리가 적절한가 (bare except 금지)
- [ ] 비동기 함수에서 블로킹 호출이 없는가
- [ ] 불필요한 코드 중복이 없는가

### 성능
- [ ] N+1 쿼리 문제가 없는가
- [ ] 불필요한 API 호출이 없는가
- [ ] 대용량 데이터 처리 시 페이지네이션이 적용되어 있는가

## TypeScript/React 체크리스트

### 타입 안전성
- [ ] `any` 타입이 사용되지 않았는가
- [ ] Props 인터페이스가 정의되어 있는가
- [ ] null/undefined 처리가 되어 있는가

### React 패턴
- [ ] useEffect 의존성 배열이 올바른가
- [ ] 불필요한 리렌더링이 없는가 (useMemo, useCallback 적절 사용)
- [ ] 컴포넌트 분리가 적절한가
- [ ] key prop이 올바르게 설정되어 있는가

### 접근성 (Accessibility)
- [ ] 시맨틱 HTML 태그 사용
- [ ] alt 텍스트, aria-label 등 적용
- [ ] 키보드 네비게이션 지원
