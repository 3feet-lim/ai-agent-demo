# Python/FastAPI 코드 리뷰 체크리스트

## 심각도 분류
| 심각도 | 아이콘 | 기준 |
|--------|--------|------|
| Critical | 🔴 | 즉시 수정 필요 (보안 취약점, 데이터 손실) |
| Warning | 🟠 | 수정 권장 (잠재적 버그, 성능 병목) |
| Suggestion | 🟡 | 개선 권장 (가독성, 중복 코드) |
| Info | 🔵 | 참고 사항 (대안 제시) |

## 보안
- [ ] 사용자 입력 검증(validation) 여부
- [ ] SQL 인젝션 방지 (ORM 또는 파라미터 바인딩)
- [ ] 민감 정보 하드코딩 여부
- [ ] 인증/인가 처리
- [ ] CORS 설정 적절성

## 코드 품질
- [ ] 타입 힌트가 모든 함수에 적용되어 있는가
- [ ] 단일 책임 원칙(SRP) 준수
- [ ] 에러 처리 적절성 (bare except 금지)
- [ ] 비동기 함수에서 블로킹 호출 없는가
- [ ] 코드 중복 여부

## 성능
- [ ] N+1 쿼리 문제
- [ ] 불필요한 API 호출
- [ ] 대용량 데이터 페이지네이션 적용
