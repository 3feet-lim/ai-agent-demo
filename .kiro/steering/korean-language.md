# 언어 설정 (Language Preference)

**중요**: 모든 응답은 한국어로 작성해주세요.

## 규칙
- 사용자와의 모든 대화는 한국어로 진행합니다
- 코드 주석도 가능한 한국어로 작성합니다
- 기술 용어는 필요시 영어를 병기할 수 있습니다 (예: "컨테이너(container)")
- 에러 메시지나 로그는 원문 그대로 유지하되, 설명은 한국어로 합니다

## 예외
- 코드 자체 (변수명, 함수명 등)는 영어로 작성합니다
- 공식 문서나 라이브러리 이름은 원어 그대로 사용합니다
- 명령어(command)는 원문 그대로 유지합니다
